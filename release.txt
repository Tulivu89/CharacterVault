# What `vault.py release <dir>` copies to the shared template (AmbiguousProphet/CiC-Vault), and what it strips.
# The release is built in memory and checked; nothing is written unless every check passes.
#
#   include <glob>                     ship tracked files that match (** spans folders)
#   exclude <glob>                     never ship these
#   keep <glob>                        files the template owns (license, sample vault): never overwritten or pruned
#   drop-line <file> :: <text>         remove each line containing <text>
#   drop-section <file> :: <heading>   remove a heading and everything under it, up to the next heading at its level or above
#   replace <file> :: <old> => <new>   replace text
#   forbid <glob> :: <text>            fail if <text> appears in a shipped file matching <glob>
#   allow <name>                       a vault name the leak check may ignore (a false positive)
#
# A drop or replace rule that matches nothing fails the release, so the rules can't rot silently.
# The leak check also fails on any character, co-writer, setting or story name from this vault.
