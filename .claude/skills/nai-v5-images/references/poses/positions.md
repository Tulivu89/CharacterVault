# Position menu

One entry per position, in v8 form: the single position tag for the base, each partner's posture for their box, the contact prose that makes the pose read, the cameras that show it, and a **Heavy** line for a fat or giant partner (`archetypes.md`). It's a starting point for a pose no set covers yet; a set module beats it whenever one exists (`INDEX.md`).

Rules that apply to every entry (SKILL.md §12, §21): one position tag; acts go `source#`/`target#` in the boxes; anatomy only in its owner's box and only when visible; prose names each body by a visible feature, with no pronouns. **Anal:** swap `vaginal` for `anal` and the box acts to `#anal`. Tags marked `?` aren't in the tag files; prose carries the pose if they miss.
