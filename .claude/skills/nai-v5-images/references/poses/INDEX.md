# Pose library — index

Read this first for any explicit or pose-driven setup. It finds the module; the set file holds it.

| File | Holds |
|---|---|
| `sets/<set>.md` | Worked modules: full setups with the set's kits, scene and style markers |

## Using it

- **By ID or name:** `[img: FB-03]`, `[img: Read Receipt]`. Add swaps in the same brackets: `[img: OFC-04 with Ilse and Hoss, Court muted]`.
- **By description:** `[img: bored, from behind, fat guy]`. Match the words against the Themes and Position columns, deliver the closest module adapted, and say in one line which one it came from. With no close match, build from `positions.md` + `layers.md` + `archetypes.md`.
- **A run:** `[img: FB-08a → 08b]`, `[img: climax ladder for FB-01]`. Each rung is its own complete setup on one locked seed.
- **Swapping characters:** every kit marker is replaced by that character's own anchors (SKILL.md A2: prompt note first), trimmed to the frame. The module keeps its camera, prose and positions; names in prose change to the new characters' visible features.

## Assembly (always)

What the user gets is paste-ready. Before delivering any module:
- Expand every marker: kits (`[TAE·SHORT]`), outfit lines, scene and light blocks, `[STYLE: <block> · <add-on>]` from `style-blocks.md` (base, then the add-on), and `[UC …]` variants written out in full.
- Write each variant as its own complete setup (SKILL.md §4). No "add this", no "same as Pose 2", no markers, nothing to piece together; only identical Model & Settings and Base UC may be shared and labeled once.
- Join cleanly: no doubled punctuation where a kit meets the next tag.

## Status

`○ untested` · `✓ tested` (held at least once; Results line says how) · `★ favorite` (the user's pick: keep its wording and don't retune it unasked).
When the user reports a result, update the module's status and add a line under its tag line: `Results: <date> ✓ seed <n>, <what held or broke>`. When the user says to save a setup as a pose: add it to the set it fits (or a new `sets/<name>.md` with a new 3-letter prefix) as ○, kits turned into markers, plus its row here and its grid cells. Commit as `Dev: poses — <change>`.
